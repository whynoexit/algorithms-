# 00 — Templates

Базовые заготовки, которые могут пригодиться при решении задач.

## Содержание

- `01_basic_template.cpp` — основной шаблон решения.
- `02_fast_io.cpp` — быстрый ввод и вывод.
- `03_debug.cpp` — простые функции для локальной отладки.
- `04_useful_functions.cpp` — небольшие часто используемые функции.
- `05_useful_macros.cpp` — несколько полезных сокращений.
- `06_local_testing.cpp` — заготовка для локального тестирования.

## Принцип

Здесь находятся только общие заготовки.

Полноценные алгоритмы и структуры данных хранятся в соответствующих разделах репозитория.
