# 01 — C++ Fundamentals

Базовые возможности C++, которые используются при решении
олимпиадных задач.

## Содержание

- `01_types.cpp` — основные типы данных.
- `02_input_output.cpp` — ввод и вывод.
- `03_conditions_loops.cpp` — условия и циклы.
- `04_functions.cpp` — функции и передача параметров.
- `05_arrays_vectors.cpp` — массивы и `vector`.
- `06_strings.cpp` — работа со строками.
- `07_pair_tuple.cpp` — `pair` и `tuple`.
- `08_stl_containers.cpp` — основные контейнеры STL.
- `09_iterators.cpp` — итераторы.
- `10_stl_algorithms.cpp` — основные алгоритмы STL.
- `11_useful_cpp.cpp` — другие полезные возможности C++.

## Цель

Довести базовые конструкции C++ до автоматизма,
чтобы во время соревнования не тратить время на вспоминание
синтаксиса и стандартных операций.
