# 02 — Basic Techniques

Базовые алгоритмические техники, которые используются
для решения задач и являются основой дальнейшей подготовки к ICPC.

## Содержание

- `01_complexity` — оценка сложности алгоритмов.
- `02_brute_force` — полный перебор и backtracking.
- `03_prefix_sum` — префиксные суммы.
- `04_difference_array` — разностный массив.
- `05_two_pointers` — два указателя.
- `06_sliding_window` — скользящее окно.
- `07_binary_search` — бинарный поиск и бинарный поиск по ответу.
- `08_ternary_search` — тернарный поиск.
- `09_bitwise` — побитовые операции и битовые маски.
- `10_recursion` — рекурсивные алгоритмы и генерация.
- `11_sorting_techniques` — использование сортировки как части решения.

## Главная цель

Научиться не просто писать эти техники,
а узнавать их по условию задачи.

Для каждой техники есть отдельный README,
где разобраны:

- главный триггер;
- признаки в условии;
- когда использовать;
- когда не использовать;
- основная идея;
- типичные паттерны;
- связанные алгоритмы;
- ограничения;
- сложность;
- ошибки;
- примеры;
- задачи для тренировки.

## Принцип

Сначала смотрим на ограничения и структуру задачи.

Затем определяем подходящую технику.

И только после этого пишем код.

Следующие разделы репозитория будут строиться
поверх этих базовых техник.
